# 验证与维护

所有命令从仓库根目录执行，使用同一个 Python >= 3.11 环境。先完成 [安装与快速开始](快速开始.md)。

## 入口与文档

```bash
python scripts/check_catalog.py
python -O scripts/check_catalog.py
python scripts/check_docs.py
python demo/run.py --check
python -m unittest discover -s tests -v
```

能力索引检查版本、公开标记与路径；demo 检查器确认 ID 唯一、包关系、脚本和指南存在；文档检查器核对本地链接目标，不校验网页在线状态、Markdown 锚点或文字内容的准确性。根目录工具测试无需 Qt。

## 可执行演示

```bash
python demo/run.py desktop-core
python demo/run.py desktop-failures
python demo/run.py desktop-contracts
# 安装 qt 后，以下命令在无显示器的 POSIX 环境运行
QT_QPA_PLATFORM=offscreen python demo/run.py desktop-ui --smoke
QT_QPA_PLATFORM=offscreen python demo/run.py desktop-search --smoke
QT_QPA_PLATFORM=offscreen python demo/run.py desktop-contracts-qt
```

交互模式需要图形会话，smoke 自动退出。根入口直接替换为同一个 Python 解释器执行包内例子，不引入常驻服务。例子自行关闭窗口、线程、数据库与日志句柄。

## 包契约

```bash
python -m pip install './packages/python/desktop[test]'
python -m pytest -q packages/python/desktop/tests/test_core.py packages/python/desktop/tests/test_contracts.py packages/python/desktop/tests/test_review_core.py packages/python/desktop/tests/test_extensions_core.py
python -m pip install './packages/python/desktop[all]'
QT_QPA_PLATFORM=offscreen python -m pytest -q packages/python/desktop/tests
```

当前 [CI](../.github/workflows/desktop.yml) 的 test/all 两组分别覆盖基础与完整依赖。执行包构建时验证 wheel/sdist；安装、目标平台或硬件行为只有实际检查后才能写为通过。文档入口调整无需重复运行无关业务或设备回归，库行为变化按受影响范围选择测试。

## 维护顺序

包内接口和测试是一手证据；包内指南解释精确使用方式；文档中心的[能力地图](能力地图.md)和[组合场景](组合场景.md)提供统一导航；根索引和 demo 清单帮助发现。增加包或场景时同时更新这些入口及 CI 路径过滤。验证记录保留真实环境、命令和结果，不把历史数字写成所有后续提交的保证。
