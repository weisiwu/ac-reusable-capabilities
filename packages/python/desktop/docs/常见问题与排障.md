# 常见问题与排障

## 无界面服务器导入 Qt 失败

只安装基础包，避免顶层导入 forms/table/crud_page 等 GUI 模块；`[test]` 不安装 Qt。确需离屏测试再安装 `[qt,test]` 并设置 QT_QPA_PLATFORM=offscreen。检查解释器与 pip 指向同一环境，勿通过注入源目录掩盖安装问题。

## SQLite 备份提示 pending writes

同一连接存在未提交事务。由拥有者根据业务结果 commit 或 rollback，再调用 backup。工具不会隐式提交，也不会为了备份删表重建。连接跨线程使用或还有其他写入者时先修复所有权。

## 备份目的文件已存在或硬链接失败

目的文件属于其他操作，不覆盖、不删除，改用唯一文件名。文件系统不支持硬链接时选择受支持目录，或另行设计具有原子无覆盖语义的存储后端，不能改为 os.replace 覆盖。

## 打印卡住或取消不立即生效

取消不能中断正在运行的外部回调。检查打印驱动/网络超时以及 GUI dispatcher 是否与等待 Future 互相阻塞；不要在 worker 回调里 close，也不要自动重试未知提交结果。

## 表单不关闭

普通字段错误会留在 error_label；自定义校验异常会发 validation_failed。监听该信号记录安全的错误摘要；取消和校验失败不应触发仓储写入。

## 服务或页面清理报告 RuntimeError

框架已经尝试剩余清理，首个根因在 __cause__。检查具体 hook 是否还有后台线程、串口或 socket；不能仅重复 start 覆盖未释放实例。

## 搜索返回了相同文字的旧结果

监听 request_started 的请求 ID，并在 set_results 中传 request_id，以拒绝相同文字的旧结果；切页时关闭或取消 BackgroundTaskRunner。旧的 search_requested 仍只携带文字，兼容用法需要应用自行处理代次。

## 库接口与文档不一致

先核对 ctf_desktop.__file__、发行版本和安装来源，再查看该版本的 contracts。不要同时安装旧源与新源的同名发行包。反馈问题附最小例子、版本、平台与错误路径，不包含账号和业务明文。
