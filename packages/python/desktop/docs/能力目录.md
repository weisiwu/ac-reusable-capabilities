# 桌面能力目录

| 能力 | 模块前缀 | 公开契约 | 可选环境 |
| --- | --- | --- | --- |
| 分页与参数化查询 | desktop.query | [query](contracts/query.md) | 标准库 |
| 密码校验与授权 | desktop.auth | [auth](contracts/auth.md) | 标准库 |
| 资料管理协调 | desktop.crud | [crud](contracts/crud.md) | 注入仓储与授权 |
| 服务生命周期 | desktop.services | [services](contracts/services.md) | 注入工厂 |
| 批量打印调度 | desktop.printing | [printing](contracts/printing.md) | 注入打印后端 |
| SQLite 迁移备份恢复 | desktop.storage | [storage](contracts/storage.md) | 标准库，明文 SQLite |
| 字节传输与串口 | desktop.transport | [transport](contracts/transport.md) | 默认工厂需 pyserial |
| 结构化日志与审计 | desktop.diagnostics | [diagnostics](contracts/diagnostics.md) | 标准库 |
| 用户目录、配置与单实例 | desktop.runtime | [runtime](contracts/runtime.md) | 仅单实例需 Qt |
| 后台任务与异步结果 | desktop.background | [background](contracts/background.md) | PyQt5 |
| 数据表格 | desktop.table | [table](contracts/table.md) | PyQt5 |
| 表单与详情 | desktop.forms | [forms](contracts/forms.md) | PyQt5 |
| 筛选与联想输入 | desktop.filters | [filters](contracts/filters.md) | PyQt5 |
| 页面导航 | desktop.navigation | [navigation](contracts/navigation.md) | PyQt5 |
| 反馈控件 | desktop.feedback | [feedback](contracts/feedback.md) | PyQt5 |
| 管理页面组合 | desktop.crud_page | [crud_page](contracts/crud_page.md) | PyQt5 与已授权控制器 |

表格与 query 构成同一类数据表格能力，查询工具也可独立调用，因此十五类能力对应十六个实现模块。稳定标识细化到公开符号，例如 `desktop.query.PageRequest`，文件迁移或文档移动不改变标识。

本包没有收录离线签名授权、故障前后现场回溯、不可变 PDF 成品缓存、原生任务进程隔离、原生编译缓存或 SQLCipher 恢复机制。它们需另行评估，不能因为当前包有 auth、diagnostics、printing、storage 就视为这些增强能力已具备。

完整接入示例见 [desktop_demo.py](../examples/desktop_demo.py)；[来源与迁入边界](来源与迁入边界.md) 区分已收录机制与后续接回工作。
