# 桌面包迁入验证记录

采集日期 2026-10-20。本地 macOS arm64，Python 3.11.15；完整环境 PyQt5 5.15.11 / Qt 5.15.19、pyserial 3.5、pytest 9.1.1。另建只安装 wheel 和 pytest 的基础环境，确认 PyQt5 与 serial 都不存在。

先构建 wheel 和 sdist，再将 wheel 安装到上述两个独立环境。测试从包目录之外运行；conftest 不再注入 src 路径，确认实际导入来自环境 site-packages。迁入源项目的测试不能替代以下提取版验证。

## 契约覆盖

测试验证参数绑定及 LIKE 字面量、空分页与非法输入；哈希与授权拒绝；CRUD 顺序和完整生命周期；服务依赖、启动回滚和反序关闭；串口注入、短写、异常与关闭；迁移原子性、无效备份拒绝、恢复回滚快照、临时连接关闭和未提交写事务备份拒绝；打印取消、进度异常、提交失败不重试与 executor 关闭；日志脱敏、审计并发及配置校验；Qt 表格状态、表单提交与取消、筛选和查询防抖、页面恢复、反馈计时器、单实例释放及管理页面交互。

仅对有实际状态和副作用的契约断言行为；索引校验脚本负责文档标签、标识和路径一致性，不替代功能测试。
