# 桌面包快速开始

本页使用当前 checkout 的 `0.2.0` 源码包，Python `>=3.11`。先确认 [依赖与环境要求](架构与依赖.md) 和 [兼容范围](升级与兼容.md)，再从仓库根目录执行下面步骤。仅看效果可回到 [在线展示](https://weisiwu.github.io/ac-reusable-capabilities/)。

## 1. 建立隔离环境

macOS / Linux：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install './packages/python/desktop'
```

Windows PowerShell：

```powershell
py -3.11 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install './packages/python/desktop'
```

使用系统允许的环境激活方式；也可直接调用 `.venv/bin/python` 或 `.venv\Scripts\python.exe`。命令中的相对路径以仓库根目录为起点。仓库根目录本身不是 Python 包，不要将 `pip install .` 当作上述安装的替代。

## 2. 完成第一次调用

保存下面代码为自己的临时脚本，然后使用刚安装包的 Python 执行。查询值对象不需要 Qt、数据库或设备。

```python
from ctf_desktop import __version__
from ctf_desktop.query import PageRequest, PageResult

request = PageRequest(number=2, size=20)
page = PageResult(items=({"name": "example"},), total=41, request=request)
assert __version__ == "0.2.0"
assert request.offset == 20
assert page.pages == 3
print(f"当前页 {request.number}，共 {page.pages} 页")
```

预期输出：`当前页 2，共 3 页`。

| 属性 | 类型 / 默认值 | 作用与限制 |
| --- | --- | --- |
| `PageRequest.number` | `int` / `1` | 从 1 开始；必须为正整数，拒绝 bool |
| `PageRequest.size` | `int` / `20` | 每页数量；必须为正整数，拒绝 bool |
| `PageRequest.offset` | 只读 `int` | `(number - 1) * size` |
| `PageResult.items` | `tuple` / 必填 | 本页记录，由调用方提供 |
| `PageResult.total` | `int` / 必填 | 总记录数；非负整数，拒绝 bool |
| `PageResult.request` | `PageRequest` / 必填 | 本次请求参数 |
| `PageResult.pages` | 只读 `int` | 向上取整的页数，空结果也至少为 1 |

分页对象只描述分页，不会自行查询、排序或校正业务数据。完整输入输出见 [query 契约](contracts/query.md)。

## 3. 选择本地演示

| 目的 | 需要的安装项 | 命令 | 应看到的结果 |
| --- | --- | --- | --- |
| 无界面组合 | 基础包 | `python demo/run.py desktop-core` | CRUD、快照、服务、打印调度示例完成 |
| 桌面交互 | `qt` | `python demo/run.py desktop-ui` | 表格、表单、筛选、反馈、CRUD、搜索六页 |
| 后台搜索 | `qt` | `python demo/run.py desktop-search` | 最新请求结果交付，可取消并关闭 |
| 异常恢复 | 基础包 | `python demo/run.py desktop-failures` | 预期异常被验证，临时资源释放 |

需要桌面交互时先安装：

```bash
python -m pip install './packages/python/desktop[qt]'
```

连接真实串口时按需增加 `serial`。执行测试才需要 `test`；完整依赖选择 `all`，各版本下限见 [安装依赖表](架构与依赖.md#安装依赖)。示例使用临时数据与模拟后端，不连接业务数据库、真实账户或真实打印机。

无图形会话时可以运行离屏 smoke；结果只说明演示逻辑走通：

```bash
QT_QPA_PLATFORM=offscreen python demo/run.py desktop-ui --smoke
QT_QPA_PLATFORM=offscreen python demo/run.py desktop-search --smoke
```

PowerShell 先执行 `$env:QT_QPA_PLATFORM='offscreen'`，再去掉上述命令开头的变量赋值。交互示例结束时关闭窗口，脚本释放自己创建的连接、窗口和后台任务。

## 4. 接入应用

```mermaid
flowchart LR
    Choose[选择能力] --> Check[核对版本与依赖]
    Check --> Run[运行最小调用]
    Run --> Inject[注入业务回调或适配器]
    Inject --> Verify[目标平台验证]
```

按 [模块指南](README.md) 阅读场景步骤，按契约查默认值、异常、信号和清理义务。普通列表先接 `query` / `table`；资料管理注入 `CrudRepository` 和显式授权；打印与串口先用模拟适配器验证再接真实设备；数据库迁移先在副本验证。

固定已审阅 commit 或有来源记录的 wheel，并确认进程只安装一种 `ctf_desktop` 来源。旧来源仓库提供同名发行包，不能通过同时安装两份来获得两个独立命名空间。升级时按 [兼容清单](升级与兼容.md) 验证，安装不会自动替已有应用完成接入。
