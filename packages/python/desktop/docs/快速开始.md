# 桌面包快速开始

## 安装选择

需要 Python 3.11+。以下命令在本仓库根目录运行，使用自己的隔离虚拟环境。

```bash
python -m venv .venv
.venv/bin/python -m pip install './packages/python/desktop[test]'
.venv/bin/python packages/python/desktop/examples/desktop_demo.py
.venv/bin/python packages/python/desktop/examples/failure_scenarios.py
```

Windows 使用 `.venv\Scripts\python.exe` 替换解释器路径。`test` 只增加 pytest，不包含 Qt 或真实串口依赖；导入 auth/query/crud/services/storage/printing/diagnostics 不需要 GUI。

```bash
.venv/bin/python -m pip install './packages/python/desktop[qt,serial,test]'
.venv/bin/python packages/python/desktop/examples/qt_showcase.py
```

Qt 示例提供表格、表单、筛选、反馈、CRUD 六个页面。需要无界面验证时：

```bash
QT_QPA_PLATFORM=offscreen .venv/bin/python packages/python/desktop/examples/qt_showcase.py --smoke
QT_QPA_PLATFORM=offscreen .venv/bin/python packages/python/desktop/examples/check_contract_examples.py --qt
```

PowerShell 先执行 `$env:QT_QPA_PLATFORM='offscreen'`，再运行 Python 命令。退出示例会释放它创建的窗口、连接和线程池。

## 按需求接入

1. 普通列表先接 query 和 table；仓储返回 PageResult，页面只负责展示。
2. 资料管理先实现 CrudRepository 和显式 authorize，再组合 CrudPage；不要在页面里复制权限规则。
3. 需要打印时先用假的 submit 验证取消/错误，再接真实设备。GUI API 通过同步 dispatcher 执行。
4. 数据库迁移和备份先在临时库或旧库副本验证，最后才接入业务数据。
5. 从 [使用指南](README.md) 逐模块确认依赖、失败及清理行为。只引用所需模块，避免在无界面入口导入 Qt 组件。

## 安装来源与版本

发行名仍为 `common-tech-framework-desktop`，导入路径为 `ctf_desktop`。0.2.0 为本轮修复版本，尚未发布到 PyPI；PR 分支不等于默认分支已更新。固定经确认的 Git commit 或使用审阅后生成的 wheel，不要同时安装不同来源的同名发行包。
