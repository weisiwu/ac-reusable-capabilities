# 升级与兼容

## 0.2.0 的兼容变化

发行名和导入路径不变，公开能力 ID 不变。0.2.0 新增修复和更严格边界：

- PasswordHasher 新增关键字 max_verify_iterations，默认 2000000；损坏的盐/摘要与越界轮数在运算前拒绝。旧的合法 16 字节盐、32 字节摘要格式保持不变；更高轮数需要显式放宽上限。
- Migration 版本改为创建时就验证正整数及回调；SerialConfig 拒绝空白端口、bool 波特率和非有限超时。原先可通过构造但随后失败的非法配置现在更早抛 ValueError。
- BatchPrintRunner 拒绝重叠 run 和关闭后运行，服务生命周期回调不允许重入注册/启动/停止。
- SQLite 备份采用同文件系统硬链接原子无覆盖发布；不支持硬链接时明确失败，不能回退到覆盖文件。
- FormDialog 新增 validation_failed(error) 信号，校验器异常保持窗口打开。CrudPage 的缺失标识走 operation_failed，而不是 KeyError 逃出槽。
- 页面关闭会处理全部页再汇总 RuntimeError；Toast 重启计时，BusyOverlay 自动适配父窗口尺寸。

## 接回项目清单

1. 将依赖固定到已审阅 commit/wheel，确认进程只安装一个 ctf_desktop 来源。
2. 在自己的 GUI、打印后端与串口环境验证；假设备与离屏测试不代表实机支持。
3. 盘点历史哈希轮数、非法配置和服务 hook 是否存在重入用法。
4. 对数据库方案核验新旧版本、用户数据保留、恢复与降级边界；本库没有业务 schema，也不会替目标项目执行迁移。
5. 原项目若要求源码保护或数据库加密，将新模块纳入其现有策略并执行开发阶段验证；本库公开源码和明文 SQLite 不满足这些要求。

## 发布状态

PR #2 的 0.1.0 基线已于 2026-10-20 合并。本次 0.2.0 通过新 PR 交付，不能在审阅前称为已合并或已发布；未上传 PyPI。

## 本轮补齐的扩展

- 新增可选 Qt 模块 BackgroundTaskRunner：一个执行槽、一个可替换等待槽，最新结果交付，协作取消与超时。不是强制杀线程的任务沙箱，不用于必须逐条执行的写入队列。
- LiveSearchComboBox 新增 request_started(id,query) 及可选 request_id 参数，旧接口保持兼容。
- configure_json_logger 新增 max_bytes 与 backup_count，默认 5 MiB / 3 份历史；max_bytes=0 可显式关闭轮转。单条记录仍可能超过阈值。
- SqliteStore、SerialTransport、ServiceRegistry、BatchPrintRunner 支持 with，调用现有清理方法，异常不自动提交 SQLite 事务。
