# 桌面能力来源与迁入边界

## 来源与许可

本包由仓库维护者拥有的 Python/PyQt5 通用桌面基础实现迁入。2026-10-20，维护者明确要求将已有能力复用至本仓库，并按本仓库 MIT 许可交付。来源基线提交为 `8664c8a14d0c42d72eab6692e201e14ce465c1c2`；迁入前来源仓库没有独立 LICENSE，不将其描述成已有 MIT 上游或第三方公开项目。此授权适用于维护者原创代码；PyQt5、Qt、pyserial 等外部依赖保持各自许可，未复制其源码或二进制。

只迁入通用实现、测试和接入文档；未迁入私有需求、账号、业务表结构、设备命令、报告模板、数据库、资源或凭据。对外不披露私有仓库地址或个人知识库路径。来源关系的内部记录保存在维护者知识库。

## 迁入方式

- 本仓库新增 `packages/python/desktop` 独立 Python 包；保留发行名 `common-tech-framework-desktop` 和 `ctf_desktop` 导入路径；PR #2 初始迁入版本为 `0.1.0`，本轮修复与扩展目标为 `0.2.0`。属于同一包的另一个源码来源，不能同时安装成两个不同包；没有发布到 PyPI。
- 源码源仓库本次不删除、不归档、不改写；切换接入项目的依赖来源属于后续工作。当前项目尚未自动改为依赖本仓库。
- 使用 `desktop.<module>.<symbol>` 稳定标识；每个公开类、函数和方法以 Python 文档字符串记录检索标记、行为、依赖、示例与测试入口。构造参数/默认值见类契约及类型签名，Qt 信号见类契约。
- 复用评估：目标仓库基线只有协作规则、贡献规范和 PR 模板，没有重复实现。直接复用已有通用模块，不从业务项目重新抽取或混入业务流程。

## 相对来源的修正

SQLite 完整性检查、快照与暂存恢复的临时连接使用显式关闭；备份存在未提交写事务时立即拒绝，避免同连接 backup 阻塞且不隐式提交。只读文件 URI 通过 `Path.as_uri()` 编码，支持含空格、问号及井号的路径。这些变化有独立契约测试。

其他模块保留原有行为，补齐文档和验证；测试不再通过 conftest 添加源码目录，要求安装包后运行。基础测试依赖不含 Qt；Qt 和真实串口保持可选。

## 能力边界

- `storage` 是标准 SQLite 明文文件保障，不提供 SQLCipher、字段加密、密钥保管、跨文件崩溃恢复或业务迁移；调用方停止其他写入并显式提交或回滚后备份/恢复。
- `auth` 提供哈希及注入式授权，不提供注册、会话、速率限制或完整身份系统。哈希来自可信、大小受限的存储。
- `printing` 提供按条准备与逐份提交，没有 PDF 成品摘要、跨请求缓存或物理打印确认。失败不自动重试；后台回调不可强制打断，调用方保证 IO 超时并关闭 runner。
- `transport` 不认识任何设备指令或帧格式；真实硬件与目标系统串口参数由使用方验收。
- `diagnostics` 只对结构化键值脱敏，不对自由文本做全面清理；应用日志支持配置轮转，审计无跨进程锁或防篡改保证。
- Qt 控件是基础实现，不包含源业务客户端的全部外观和功能。CRUD 使用同步仓储 IO；慢查询需接入方安排异步。联想输入兼容文字比较，并支持可选请求 ID；可用 request_started ID 与 set_results(request_id=...) 拒绝同文字的旧请求；不传 ID 的旧接口仍只有文字校验。
- 页面退出与销毁由调用方管理；Toast 重启一个拥有的计时器；BusyOverlay 自动追踪父窗口尺寸。这些行为已在公开契约中标明。

## 升级与保护

本次为独立公共源码包迁入，不修改任何业务客户端、业务库、密钥、打包配置或安装包。新旧业务数据库兼容和升级路径未因此获得验证。MIT 公开源码不提供混淆、原生编译或源码加密；不能把本包的 SQLite 工具描述成整库加密。接回任一项目后仍需验证数据迁移、代码保护清单、密钥保留和目标平台行为。
