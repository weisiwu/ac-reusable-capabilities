# 桌面能力评审与修复记录

## 范围与方法

2026-10-20，基线为 PR #2 合并提交 `38148aae5ccf32b8d498ac098ae5cae0b6d0d79d`。审查原有全部 15 个实现模块、测试、构建清单、示例与目录工具，并复查新增 background 模块。目标版本 0.2.0；源码、契约及实际运行结果作为证据，不以命名或风格偏好认定缺陷。

先为确认问题建立复现用例：第一批 22 个用例失败，修复后通过；表单和管理页面另有 3 个失败用例，修复后通过；随后补充导航、资源关闭和扩展边界的验证。首次失败记录保留于本次审查运行态，不把运行日志、私人目录或业务数据提交公共仓库。

无 GitNexus 索引，本轮使用定向源码、公开契约、依赖与回归用例审查，没有自动建立图谱。以下是本次确认并处理的问题，不代表对所有未来输入或所有系统的无缺陷证明。

## 全能力覆盖

| 能力领域 | 已审查部分 | 结果与保留边界 |
| --- | --- | --- |
| query / table | 值绑定、字段白名单、页码、模型更新和选择 | query 原契约无新增确认缺陷；修复表格异常路径；不自动改业务 SQL |
| auth | 哈希格式、工作因子、用户查找和权限回调 | 修复解析与工作上限；限流、会话等仍属应用 |
| crud / crud_page | 授权和校验顺序、写后通知、弹窗与错误信号 | 修复页面主键/清理；changed 回调在写后，应用不得因通知失败盲目重试写入 |
| services | 依赖拓扑、启动失败、停止失败和重入 | 修复清理及状态守卫；工厂返回前的资源由工厂自行清理 |
| printing | 准备、逐份提交、取消、错误、关闭与线程 | 修复执行互斥与关闭；未知出纸结果不自动重试 |
| storage | 版本迁移、快照、恢复及连接清理 | 修复原子无覆盖和版本校验；明文 SQLite，未增加密钥或业务 schema |
| transport | 配置、短写、读取、错误和关闭 | 修复非法配置及关闭重试；未做真实设备验收 |
| diagnostics | 脱敏、handler 重配、并发与容量 | 修复策略更新，增加轮转；不清洗任意自由文本、不提供防篡改审计 |
| runtime | 用户目录、JSON 校验、Qt 单实例释放 | 现有契约未发现新增可证实缺陷；不是授权或跨机器锁 |
| forms / filters | 字段初值、重复键、验证错误、选项更新与代次 | 修复数据与回调边界，增加请求 ID |
| navigation / feedback | 进入离开失败、销毁、计时器与尺寸 | 修复失败恢复、槽隔离、重入、完整清理及提示状态 |
| background 新增 | 最新请求、有界等待槽、Qt交付、取消、超时、销毁 | 独立契约测试；外部 IO 必须有限、协作退出 |

## 补齐的通用扩展

1. BackgroundTaskRunner：单执行槽、单可替换等待槽，结果回到 Qt 线程；区分失败、取消与超时，忽略迟到结果，关闭和父对象销毁时取消。
2. 联想搜索 request_started(id,query) 及 set_results 的可选 request_id，拒绝相同文字的旧响应；旧接口继续兼容。
3. 日志 max_bytes/backup_count，默认 5 MiB/3 份历史；0 关闭轮转，单条超长日志可超过文件阈值。
4. SqliteStore、SerialTransport、ServiceRegistry、BatchPrintRunner 的 with 资源管理，不重复实现关闭逻辑，不隐式提交数据。

每项扩展有使用指南、契约、可运行例子和失败测试。详见 [文档导航](README.md) 与 [升级兼容](升级与兼容.md)。实际安装验证见 [验证记录](验证记录.md)。

## 未验证与边界

没有验证真实打印机、串口、Windows 安装包或任何业务数据库升级。后台取消不是抢占式超时；不合作的驱动调用不能由 Python 线程安全强杀。没有新增数据库加密或源码保护能力。源项目未切换依赖。以上是接入责任边界，不应写成已通过的集成验收。
