# 安全与数据边界

## 认证与授权

PasswordHasher 只校验 PBKDF2 密码存储值；它不等于完整登录系统。应用提供安全账号存储、限流、锁定及会话生命周期。默认验证上限避免损坏载荷触发无界 PBKDF2 工作；已有更高轮数时显式配置 max_verify_iterations 并规划升级，不能直接重置用户口令。

AccessPolicy 和 CrudController 强制应用给出授权逻辑，但更深层、对外暴露的仓储入口也需要相应控制。隐藏按钮、只读表单、单实例锁都不提供数据授权。

## 数据与 SQL

SqlWhere 只绑定值，columns 中的表达式必须来自受信配置。SQLite 工具没有整库或字段加密，没有密钥轮转和加密备份承诺。恢复前应用停写、关闭外部连接，恢复后核验业务关系；迁移失败回滚不代表支持任意旧客户端降级读取。

## 日志与审计

只对结构化键值脱敏；自由文案、异常消息、actor/resource 标识可能含敏感信息。默认 secret key 列表不替代业务敏感字段清单。同一 logger/path 更新策略会更新 formatter。审计文件是追加式记录，不是防篡改账本，也没有跨进程写入保证。

## 代码和依赖

本仓库提供 MIT 公开源码，不提供混淆、源码加密或原生编译保护。PyQt5、Qt、pyserial 等独立依赖保留自身许可，公开原创代码的 MIT 不会改变第三方依赖的使用和分发条件。接入项目自行确认打包方式与依赖许可，框架不替代其发布审查。
